# Changelog

## 0.1.0 — Initial open-source release

- Local jobs, supervised pipelines, and parallel task-graph runs in isolated Git worktrees.
- Codex CLI and Cursor agent adapters with configurable engineering roles.
- Explicit attention/decision flow, integration checks, final review, and approved local landing; no automatic pushes.
- Read-only evidence inspection, optional tmux dashboard, and optional verified webhook notifications.
- Public documentation, synthetic regression fixtures, clean-install CI, and Apache-2.0 licensing.
- One-instruction Grok Bot setup guide (`docs/grokbot-setup.md`), English and Chinese READMEs, design specs under `docs/specs/`, and a tag-triggered GitHub Release workflow.
