When reporting a temporary workspace file, include policy_incidents[] linking each entry to policy_violations by violation_index. Use category temporary_workspace_file, a worktree-relative path, and cleaned true only when the file is gone before exit. Cleaned empty temporary directories and temporary files in $TMPDIR need not be reported as violations. Invalid incidents are stripped with a normalization warning and remain fatal; they cannot qualify for self-report downgrade. Use [] when none apply.
